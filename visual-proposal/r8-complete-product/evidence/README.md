# R8 Proposal QA Evidence

Store proposal-only review evidence here: viewport screenshots, state matrices, contrast results, asset hash reports, rights/provenance checks, responsive comparisons and final-main reconciliation evidence.

Evidence must identify the exact product-main commit studied and the exact proposal package version it validates. Do not combine results from different heads as if they were one acceptance run.

This folder does not replace the senior developer's production CI or release proof. It exists so the finished visual proposal can be reviewed quickly and reproducibly before implementation.

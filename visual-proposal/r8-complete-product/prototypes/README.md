# R8 Proposal Prototypes

Use this directory for production-quality visual reference prototypes only.

Prototype code must be presentation-only, namespaced, reversible, and isolated from production authority. It may mirror current DOM structure for fidelity, but it must not become routing, storage, scoring, Firebase, Save Library, pairing, Remote Joining or shared-play authority.

The purpose is to let the senior developer review the intended final product with minimal interpretation before choosing how to integrate it into the then-current application.

Do not patch `main` or deploy Pages from this visual track. If live-product study reveals a visual defect, record the finding and demonstrate the corrected proposal here.

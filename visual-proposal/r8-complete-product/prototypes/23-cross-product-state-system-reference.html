CROSS-PRODUCT STATE GRAMMAR

EMPTY · WAITING · OFFLINE · STALE · ERROR · SUCCESS

EMPTY

Nothing here yet

Neutral explanation with one useful next action when product authority provides one. Never show fake sample data as real.

WAITING FOR OTHER MANAGER

Waiting for Nik

Calm and explicit. Waiting is not an error and does not encourage repeated manual refresh when the runtime already observes state.

OFFLINE / PROVIDER UNAVAILABLE

Connected features unavailable

Local Career Mode remains available where product authority says so. Do not imply local saves are lost.

STALE / CONFLICT

Review again before applying

No unverified mutation is implied. Amber points to refresh, retry or re-review rather than destructive reset.

DESTRUCTIVE / CRITICAL RECOVERY

Recovery intervention required

Red is reserved for genuine data/recovery risk. Unrelated actions freeze when the runtime requires it.

CONFIRMED SUCCESS

Backup prepared

Success text describes exactly what happened. Export success never implies cloud backup or remote synchronization.

Reduced motion: state changes remain immediate and complete without decorative movement. Focus: live updates do not steal focus. Color: every state has explicit text and action semantics. Responsive: cards stack before typography or hit targets are compressed. Character art is omitted because these are reusable system states.

# R8 Complete Product Asset Build Matrix

Status: ACTIVE — proposal cannot close until every REQUIRED item is packaged and verified.

This matrix separates "an asset is required" from "a new raster image must be generated." CSS/SVG/procedural graphics, existing frozen masters, derivatives and character-free layouts are valid assets when they solve the visual role better than a new image.

Random image generation is prohibited. New generation is allowed only after a screen-specific brief defines the exact unsolved role, safe zones, dimensions, rights constraints and acceptance checks.

## Asset packaging rules

Every packaged asset must have:

- stable ID;
- filename;
- source/provenance;
- dimensions;
- file type;
- SHA-256;
- target screen/surface;
- responsive eligibility;
- safe-zone requirements;
- rights status;
- generation/model note if generated;
- acceptance status.

Do not bake core UI labels into images. Text belongs to real DOM whenever possible.

Do not use official club crests, proprietary FIFA/EA fonts, copied EA menu graphics, downloaded soundtrack files or unlicensed player photography as new R8 assets.

## Completion rule

This matrix reaches COMPLETE only when each required role has either:

1. a packaged and verified asset, or
2. a recorded decision that the role is intentionally solved with existing DOM/CSS and requires no external asset.

A blank asset slot, placeholder, unresolved generation decision or unverified file blocks final senior-developer handoff.

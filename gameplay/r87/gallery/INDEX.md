# r87 gallery — do not merge

Source: `gameplay/r87` at `cafdaf3d4c9eec958f1cd2f5e9bb0f8302c40d7c` (latest remote head, checked again after capture, 2026-10-30 UTC). **Partial gallery: the core 3D roulette states were not retained.** 39 PNGs; desktop 1440×900, phone 390×844, plus 360×780 signing view. Each PNG is below 1 MB. Larger screenshots use indexed PNG compression without resizing.

Only this gallery is committed. No game, test, Rules source, dependency manifest, or workflow changes. Temporary screenshot hooks and runtime overrides were removed. Setup: `npm ci`, `npm i --no-save firebase@12.17.0`; repo static server and `test:ce2pg`; Playwright Chromium build 1234 (151.0.7922.34), obtained from Google's storage mirror because the Playwright download host was blocked. Firebase used only local Auth/Firestore emulators, project `demo-cms-browser-journey`; no production Firebase. The repo-generated emulator Rules artifact was rebuilt after an initial stale-artifact start failure.

Live photography: separate desktop RUN=1 and phone RUN=2, `CE2PG_PLAN=single CE2PG_SEASONS=3`. Desktop committed seasons 1 and 2, then was stopped during a stalled post-reload capture (92/97 checks, 7 problems). Phone committed season 1, then Chromium crashed (43/46 checks, 5 problems). Both are FAIL/incomplete, not three-season or production acceptance evidence. Some failures compare old W/D/L abbreviations with the new “won, drawn, lost” copy. An additional mixed-size photography pass reached seasons selection, league and club confirmation; it then timed out opening Transfer Challenge (15/15 recorded checks, 2 fatal problems). Its paired setup shots resize the same live Daniel page.

Static photography: repository `scripts/gate-screenshots.mjs --files-file <list> --out <dir>` / SCREEN_MAP, with temporary exact viewport and Rule Book scroll hooks. Home, Rule Book and the explicitly marked static Season Results form use signed-out local contexts. The static form's existing default values are not a played result. Everything else is from emulator gameplay. The r86 comparison was checked against `origin/gameplay/r86`; unchanged r86 reveal phases are omitted. Settled images alone do not prove absence of transient old-design flashes.

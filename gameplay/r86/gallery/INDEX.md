# r86 release gallery — do not merge

Source: `gameplay/r86` at **fb38a6638d265859cc9433783fff11ef50d84e6c**, still the latest branch head when publication was prepared. Only this gallery directory is committed. No game, test, Rules source, dependency manifest, or workflow changes.

58 PNGs. Desktop **1440×900**; phone **390×844**; additional Home **440×956**, Select League **412×915**, Rule Book landscape **844×390**. Every PNG is below 1,000,000 bytes. Large PNGs use a 256-colour palette to meet the limit; viewport dimensions were preserved. Images were reviewed at full size or in contact sheets, with close inspection of text and chip views.

The captures use the repository’s static server, `scripts/gate-screenshots.mjs` and `tests/browser/ce2pg-journey.cjs`. Local-only wrappers set the requested viewports and take extra photographs through the existing UI; none are committed. `npm ci` completed. Playwright 1.62.1 Chromium 151.0.7922.34 was used: the normal installer’s CDN was blocked, so its matching official Chrome for Testing build was downloaded from the allowed Google storage host. Static captures use the Gate’s offline/service-worker isolation. The Special Player page uses local three.js r128 and local copies of its requested fonts; its shipped `__mq` preview clock selects the actual ladder, flash, hold, report, handover and ending frames.

Live captures use **only Auth/Firestore emulators, demo-cms-browser-journey, on loopback**. Current composed Rules were generated with the repo builders into a scratch artifact; the pre-existing generated artifact and every Rules source were left unchanged. The initial SDK-version and stale generated-artifact setup failures were corrected locally before retaining live pictures. Production Firebase was not used.

Both primary journeys played all **three seasons**, automatically closed the Showdown, and reached the completed career pages. Each primary run: **257/281 checks, FAIL**. Each run’s 24 failures are Career Statistics table and Trophy Room rank text extractors: they expect the numeric values immediately after Daniel/Nik and do not account for the new SP chip text. The displayed figures were retained, not patched. Both runs finished their post-close storage-wipe and fresh-browser checks with no fatal error; this gallery does not claim a green test suite. An additional mixed-size one-season run supplied closer chip/counter framing: **153/182, FAIL**, including the same extractors, responsive full-text comparisons, and a Save Library changed-in-another-operation console diagnostic during storage-wipe capture work. No assertions were weakened or test files edited.

Standalone reveal previews deliberately select rank 1 (Neymar) or rank 200 (Bruma) for both managers to compare tier rendering. These are the page’s real preview selections, not claimed to be a legal in-game pair: real draws never give both managers the same player. Rank 200 stops its ladder at bronze. White-flash pictures are intentionally washed out. Still frames do not establish the absence of transient old-design flashes throughout a journey.

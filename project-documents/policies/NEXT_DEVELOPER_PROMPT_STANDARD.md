# Next Developer Prompt Standard

Canonical policy: `00_HANDOFF_GOLDEN_RULE.md` → `Mandatory repository-first next-developer copy-paste prompt`.

Every future handoff that recommends a fresh developer/chat must give the owner one concise ready-to-paste repository-first prompt generated from the current verified boundary. It must direct the successor to the live repository and current `START_NEXT_SESSION_...md`, require independent verification and a fresh WEC, route to `IMMEDIATE NEXT TASK AFTER FULL STUDY`, and state that live source/evidence overrides stale handoff prose.

This compact mirror does not replace the canonical rule or the full SLE package.

## 4. Confirmed game and card eligibility rules

1. Legends: FIFA 14–17 were the Legend era, and Xbox was the Legends platform. FIFA 14 used HEA on the face instead of PHY, making FIFA 14 cards ineligible for this six-stat dataset. Use FIFA 15–17 Legend versions for this study.
2. FIFA 18–23: allow only the Prime Icon of each edition. Reject Base/Mid from these editions and reject Prime Icon Moments, World Cup, TOTY, Trophy Titans, Cover Stars, and all other special versions.
3. FC 24–27: use the standard Base Icon; exclude Debut, Champion, and event/promo versions. The latest release in scope on 31 October 2026 is FC 27.
4. Choose the highest OVR among all allowed cards for the person; if tied, select the newer title. Make sure the position, nation and all six stats are taken from that exact edition and version.
5. All eligible players are male and outfield. FUT Heroes, goalkeepers and women are excluded from this database.

## 6. Data-quality and ambiguity notes

- `accepted_names` is unique under case-insensitive, accent-insensitive normalization. Bare `Laudrup` is deliberately not an accepted guess: two eligible players (Brian and Michael) share it. Full names remain accepted. Similarly, the ambiguous surname `Hernández` was removed from the existing Xavi Hernández row so it can identify Luís Hernández unambiguously.
- The older FIFAUTeam.com FIFA 17 Legend ratings table is not a literal image of each individual card. Some Legend rows refer to this table and are marked `independent card-face validation pending` in CSV `notes`; this is a known gap relative to the strict handoff's card-face-source requirement.
- FC 27 includes separate Debut/Champion upgrade ratings that must not be conflated with the standard Base Icon. For example, the new Pepe Icon has a verified FC 27 standard Base rating of 89, despite separate debut/upgrade reporting.
- Many older card histories expose other editions that are not yet explicitly listed as candidate rows. `icon_cards_considered.csv` therefore validates that File A wins *among recorded comparisons only*. It does **not** yet establish that each selection is the maximum across every eligible historical edition.
- A few full common names and names printed on cards differ. The CSV distinguishes `full_name`, `card_name` and `accepted_names`; Claude should check exact visual card spelling before deployment.
- `source_url` is typically a dedicated player history or card detail page; each should be opened to check the version label, overall and face numbers rather than trusting only the player summary.
- Card values were transcribed from source pages in this research pass, but the full independent, second-source 20-random-plus-top-10 QA sample required by the handoff has not been completed.

## Future production certification

For every song that survives Nik's listening pass, create a record containing:
- exact Audius track id;
- exact Audius permalink;
- uploader and whether it is official, credible reupload, remix, or fan upload;
- current isStreamable/API result;
- stream endpoint test;
- explicit/clean status;
- duplication/version decision;
- availability verification date;
- durability grade A/B/C;
- soundtrack-fit score;
- intended game context;
- final accept/reject reason.

No game code or main branch change is authorized by this listening pool.

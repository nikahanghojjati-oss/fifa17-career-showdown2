# Missing marquee player stats handoff

Nine previously unmatched players have all six summary stats, overall and primary preferred position directly available in the FIFA 17 Career Mode export linked in the CSV. No values were calculated from sub-attributes.

The CSV contains the nine additions. The JSON contains all 200 original rows, with 190 previously sourced original FUT base-card sets retained, nine Career Mode fallbacks inserted and Gabriel Jesus still unresolved. The source-club field is separate from the supplied club; where the clubs differ, the values are evidence for the named player in the early snapshot, not a verified card at the later club. Do not conceal this distinction.

The nine fallback sets come from SoFIFA-derived roster 170002, as recorded by all player URLs in a 17,597-record community export. The exact calendar date of that snapshot has not been independently verified. These are published Career Mode summary values, not confirmed September FUT cards or proof of game version 1.11 membership. The six labels have the same names as FUT labels, but their values should not be assumed identical. Existing competition ranks and potential values remain original-list metadata and were not reranked or revalidated by this stat patch.

Gabriel Jesus (list index 18, ID 230666) is absent from this export. Contemporary reporting about his default Career Mode availability conflicts with that absence. His status remains unresolved; this file does not authorize deletion from an actual v1.11 database.

# HO-071 · One handcrafted title family · 3 samples for Nik

Built in code (no picture ticket, no AI generation): real letterforms + matte material, letters only on alpha.
No shine, no bevel, no glow, no crown, no kicker, no box behind.

| Option | Look | Font (all SIL Open Font License, free for web) |
|---|---|---|
| A Honours Board | gold-leaf sign-writing like a club honours board, small dark painted shade | Cormorant SC Bold |
| B Brass Inlay | matte brass condensed caps set into the wall, thin dark cut edge | Big Shoulders Display ExtraBold |
| C Sign-writer's Script | hand-painted script, thin dark outline (closest to today's brush) | Yellowtail |

- Pick sheet: `HO071_PICK_SHEET.jpg` (TRANSFER WAR on the HC V2 Board room, SETTINGS on the HC slab, 1920-wide slot, same cap height).
- Close-up: `HO071_CLOSEUP.jpg` (material at 2x).
- Renderer: `tools/title_family.py` (all titles share cap height, stroke and baseline by construction).

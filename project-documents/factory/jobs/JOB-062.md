## Steps

Do them in order. After each step update `project-documents/factory/status/JOB-062.md` and push with the message `Job 62 step k/9: <step name>`.

1. Set up `visual-assets/v10_1/career-statistics/` by copying the structure of `visual-assets/v10_1/home/` (index.html, css, js, tools/build_preview.py) and renaming. Link `../shared/showdown-tokens.css`, `showdown-type.css`, `showdown-ui.css`, `stage.css`, `motion.css` and the shared JS. Read `visual-assets/v10_1/career-statistics/TRUTH.md` and `fixtures.json` (from the truth job) and render every frame from fixtures.json via `?frame=`.

2. Stage: load `visual-assets/v10_1/career-statistics/assets/ENV_*_PLATE_V1` through the stage engine. REGISTRATION RULE: at 16:9 (1920 × 1080, 1366 × 768) the plate is drawn exactly where the mockup has it (cover, centred, no extra zoom, no shift), so Daniel, Nik, hands and stadium are the mockup's own pixels in the mockup's own places. Other desktop ratios may crop edges but never scale faces more than ±5 % from the 16:9 position. Atmosphere layer on. Mark the managers' areas with `data-manager="daniel"` (left) and `data-manager="nik"` (right) for the QA harness.

3. Title block: the screen title is the brush wordmark IMAGE (`TITLE_*_V1.webp` from the plate or wordmark job) with the real words in visually-hidden text for screen readers, never a font. Eyebrow and tagline in the shared type classes. Place everything exactly where the mockup has it (measure the mockup: centre x, top y, width as % of the frame). No dark box behind text unless the mockup has one there; the plate is fully clean, so UI floats on the scene. Every illustrated object in the mockup (trophy, icon art, frame) gets a real art asset, not a flat box.

4. Main layout (desktop, ≥ 1024 px): Title block top centre, headline tiles centred below it, spanning between the two managers' inner shoulders (do not cover faces). Career Table panel (about 36 % width) and Manager Comparison panel (about 22 % width) side by side; Leaders row below; button row at the bottom. Numbers: tiles 64–72 px Barlow Condensed 700 gold; table numbers tabular, leader's points in gold.

5. Build the mockup elements one by one, following the two lists above ("what to take" and "product truth") and the KEEP / CHANGE / DROP table in TRUTH.md. Measure each element's position and size on the mockup (as % of 1366 × 768) and match it within about 2 %. Every word that can change is DOM text from fixtures.json.

6. Depth sandwich: Daniel's crossed arms sit behind the Career Table's left edge in the mockup; better: cut out his forearm so it rests in front of the panel's left edge with a contact shadow. Nik's hand on chin stays clear of all panels. Make the cut-outs with `shared/tools/cutout.py` from the platemap polygons; add rim light and contact shadows.

7. States: build every frame in fixtures.json (CS1 several Showdowns (preview data) · CS2 new career (empty) · CS3 partial history with coverage note · CS4 unavailable). Preview frames show the "Preview data" chip. Empty, partial and unavailable states are designed panels with an icon and plain words, never blank space.

8. Desktop QA: run `shared/tools/factory-qa.cjs` for all frames at the desktop sizes; run the mockup-diff gate on the main frame at 1920 × 1080 (`python3 visual-assets/v10_1/shared/tools/mockup_diff.py --mockup <mockup> --build <shot> --plate <plate 1X> --platemap <platemap.json> --out visual-assets/v10_1/career-statistics/evidence/diff/`) and make it PASS (faces ≥ 0.90, other protected boxes ≥ 0.75, SSIM ≥ plate SSIM − 0.15, ΔE ≤ plate ΔE + 6). Check page weight on first paint ≤ 900 KB desktop (WebP, `<picture>`, never ship PNG masters). Iterate until your own scoring against QUALITY_BAR criteria 1–7 and 10 is at least 4 each.

9. Write `visual-assets/v10_1/career-statistics/BUILD_RESULT.md` (how to run, frames, what you changed from the mockup and why, QA results, known gaps) and `preview.html` with build_preview.py. Commit and finish.

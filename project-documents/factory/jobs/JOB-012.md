## Steps

Do them in order. After each step update `project-documents/factory/status/JOB-012.md` and push with the message `Job 12 step k/6: <step name>`.

1. Collect the colours, fonts and sizes the four built screens already use (grep their CSS). Write the list into `visual-assets/v10_1/shared/TOKENS_NOTES.md` with where each value came from. Where screens disagree, pick the value closest to the mockups and say why.

2. Write `visual-assets/v10_1/shared/showdown-tokens.css`: CSS custom properties prefixed `--sd-` for black/panel/glass, the gold ramp (`--sd-gold-100…900`), text colours, manager accents (`--sd-daniel`, `--sd-nik`, taken from main's CSS if they exist), edge widths, corner cut size, radius, 8 px spacing scale, shadows (contact, panel, glow), z-index layers for the depth sandwich (plate 0, atmosphere 1, ui 2, cutout 3, light 4), and motion durations/easings.

3. Add `@font-face` for Kaushan Script, Barlow Condensed 600/700 and Barlow 400/600 from `visual-assets/v10_1/tr2/slice-02-plate/assets/fonts/` (copy the woff2 files to `visual-assets/v10_1/shared/fonts/`, `font-display: swap`).

4. Write the title system in `visual-assets/v10_1/shared/showdown-type.css`: `.sd-eyebrow` (crown + letter-spaced line), `.sd-title` (brush, metallic gradient text with `background-clip:text`, dark outer shadow, slight skew on the title only), `.sd-tagline`, `.sd-label`, `.sd-number` (tabular, condensed, 3 sizes), body text. Titles scale with `clamp()` between phone and 1920 desktop.

5. Build `visual-assets/v10_1/shared/specimen.html`: every token swatch, the title block with "TROPHY ROOM" and "SEASON RESULTS", number sizes, labels, on the dark stadium plate from `visual-assets/v10_1/home/assets/ENV_HOME_PLATE_V1_1X.webp` as background.

6. Screenshot the specimen at 1366 × 768 and 393 × 660 into `visual-assets/v10_1/shared/evidence/`, put it side by side with the title area of MOCKUP_TROPHY_ROOM.png, and adjust until the title reads as the same family (weight, gold, glow). Commit and finish.

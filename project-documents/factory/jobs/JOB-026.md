1. Load the mockup in Python. Draw the edit zones as rectangles (and polygons if needed) covering everything listed under Remove, with an 8 px margin, but never touching a face, hand or hair. Save the zones as `visual-assets/v10_1/legacy/assets/plate_zones.json` (pixel coordinates in the mockup's size) and a guide image `visual-assets/v10_1/legacy/assets/GUIDE_LG_PLATE.png` = the mockup with the zones filled in solid cyan (#00FFFF).

2. Image edit (one request) on the guide image with exactly this prompt:

```
Edit this image. Repaint every solid cyan area so it shows what would naturally be behind it: the night stadium, crowd bokeh, floodlights, banners and dark atmosphere, continuing the existing perspective and the warm golden lighting. Where a person's body was covered, continue their clothes naturally. Keep everything that is not cyan exactly as it is: same people, same faces, same hands, same pose, same framing. Remove all cyan. ```
```

4. Likeness lock in Python: resize the edit to the mockup's exact size; build a mask from the zones feathered 6 px; output = edit inside the mask, original mockup outside. Save `visual-assets/v10_1/legacy/assets/ENV_LG_PLATE_V1_SRC.png` (lock result at source size).

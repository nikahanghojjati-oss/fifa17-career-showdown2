# JOB-1468 — long names, stage 1 CSS audit

Scope: read-only static review of `css/v10Shell.css`, `css/v10Club.css`, `css/v10Transfer.css`, and `visual-assets/v10_1/season-results/season-results.css` at `qa/mega-audits`. Stress targets: 14-letter manager names and 22-letter club names; transfer player names. Findings are CSS-derived risks, **not reproduced browser failures**. No gameplay or frozen Team V file was edited.

## Findings (6 maximum-impact candidates)

1. **Season Results / manager heading (desktop and phone).** `visual-assets/v10_1/season-results/season-results.css:303-327,1084-1097,1397-1399,1651-1653`. `.manager-card-header` uses `grid-template-columns: auto 1fr`; `.manager-name` has no `min-width: 0`, overflow rule or ellipsis. A long unbroken manager name can impose its min-content width, overflow the fixed-width `.entry-panel` or be cut by the panel's `overflow: hidden` (line 290). **Smallest CSS fix, in a non-frozen production override:** make the text track `minmax(0,1fr)`, and on `.manager-name` use `min-width:0;max-width:100%;overflow:hidden;text-overflow:ellipsis;white-space:nowrap`. Retain existing font sizes.

2. **Season Results / club subtitle (desktop and phone).** `visual-assets/v10_1/season-results/season-results.css:329-336,1099-1102,1401-1403,1650-1653`. `.manager-club` has no one-line containment; a 22-letter club name with `letter-spacing:.16em` can wrap, expand the header, and consume vertical space reserved for scoring fields in the fixed-height card (lines 126-129, 285-290). On short phones it is explicitly made visible again at line 1652. **Smallest CSS fix:** in an allowed production override add `min-width:0;max-width:100%;overflow:hidden;text-overflow:ellipsis;white-space:nowrap` for `.manager-club`, together with the track fix in finding 1.

3. **App/Team V shared top bar / identity badge (Home and desktop screens).** `css/v10Shell.css:21-39,48-59,182-195`. `#onlinePlayerIdentityBadge` and `#seasonIndicator` are auto-width `inline-flex` chips in an auto-width, fixed-position `#topHeader`; no maximum width or truncation is specified. If the identity badge includes a longer manager name, the row can extend left into navigation or a screen title rather than shrink. **Smallest CSS fix:** constrain the identity chip with a responsive `max-width`, `min-width:0`, `overflow:hidden`, `white-space:nowrap`, and ellipsis on its text-bearing child (or a block text wrapper); apply in both Home and other-screen selectors. This is contingent on actual badge text, which these CSS files do not show.

4. **Transfer War / typed player name in signing row (phone).** `css/v10Transfer.css:53-54,62-81`. The portrait four-column grid reserves two `minmax(100px,...)` selectors while the name track can shrink to zero (`minmax(0,1.08fr)` at lines 76-78); this bridge CSS does not constrain the embedded input/combobox's intrinsic width. Long player names or a narrow phone could make the field protrude into the selector columns or truncate the visible input area. **Smallest CSS fix:** set `min-width:0;max-width:100%;box-sizing:border-box` on the row's name input and combobox elements, while keeping selector touch targets and existing column order. Needs DOM/phone confirmation: the underlying Team V transfer stylesheet was outside this ticket's permitted read set.

5. **Club Assignment / shared presentation status note (desktop).** `css/v10Club.css:122-132,157-161`. `#sharedShowdownPresentationStatus` is pinned top-left with `max-width:min(520px,30vw)`, but has no max-height, clamp or scroll boundary. A status line containing a long manager or club name could wrap into multiple lines, growing the note down over the reveal art; the phone rule also has no line limit. **Smallest CSS fix:** if names actually appear in this status, place the name in a `min-width:0;overflow:hidden;text-overflow:ellipsis;white-space:nowrap` child, or constrain just the name-specific span rather than truncating essential status instructions. Dynamic status content is not established by the four permitted CSS files; verify before scheduling.

6. **Season Results / review panel text.** `visual-assets/v10_1/season-results/season-results.css:479-485,1025-1037,1197-1249`. `.season-review-panel` is a fixed-size `overflow:hidden` box. The `.seasonReviewResult` content has line-height but no long-token breaking rule; when result text includes a long manager/club name, its line can overrun or the additional wrapping can be clipped, especially on short phones. **Smallest CSS fix in a non-frozen override:** add `min-width:0;overflow-wrap:anywhere` to the result text and give the panel's content region bounded `overflow-y:auto` where necessary, without moving the fixed action row. Whether results contain those names requires runtime confirmation.

## Coverage and limits

The four ticket-listed files were inspected. `v10Club.css` intentionally reverts `.clubManager`, `.clubCardFace strong`, and `.clubConfirmationSide strong` to later Team V declarations (lines 61, 75, 88); their final name-overflow behavior cannot be certified without the frozen club stylesheet, which this job did not read. The same limitation applies to the Transfer War skin. No claim of a full-screen/browser pass is made. Recommend the lead reproduce with a 14-character unbroken manager name, a 22-character unbroken club name and a long player name at 360×640, 375×553, and 1536×864 before converting candidates into fixes.

No changes were made to gameplay, app UI, Team V art/CSS, or tests.

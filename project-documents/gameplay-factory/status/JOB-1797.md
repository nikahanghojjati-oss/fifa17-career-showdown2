## Finding 1 · SURE · Statistics dependency failure is handled too late

File and original lines: `js/optionalModules.js:337–340`.

What the player sees: opening Career Statistics or Rivalry Statistics with a fast failed analytics stylesheet and a slower analytics script produces an unhandled application error. The Statistics button remains busy and the module remains loading until the script finishes or times out, although the stylesheet has already failed.

Why: the stylesheet and required presentation promises start first, but their rejection handlers are only attached after the script loader completes:

```js
const visualPromise = ensureRequiredFootballVisualExperience();
await ensureStatisticsScript();
await Promise.all([stylePromise, visualPromise]);
```

Smallest change: await `Promise.all([stylePromise, visualPromise, ensureStatisticsScript()])` immediately. The script's internal analytics-before-statistics order is preserved. Any failed dependency now reaches the existing error handler immediately; the busy state clears and the failed stylesheet can be retried. Pending scripts remain deduplicated by the existing runtime loader.

Uncommitted Node repro called the real `openOptionalModule`, `ensureStatisticsModule`, `loadRuntimeStyle`, and `loadRuntimeScript` against controlled DOM load/error events. Required presentation was treated as already prepared. The analytics stylesheet failed while the analytics script remained pending.

Before:
```json
{"unhandled":1,"result":"pending","state":"loading","busy":"true"}
```

After:
```json
{"unhandled":0,"result":false,"state":"error","busy":"false"}
```

Exactly one new contract file was added: `tests/contracts/work-audit-optional-modules-b-contracts.cjs`. Before the fix it failed with `1 !== 0` unhandled rejections. Afterward it passed and proved immediate failure handling, error/busy cleanup, retrying the failed stylesheet, reusing the pending analytics script, opening only Career Statistics, and no asset reload after readiness. It is registered last in both required registries.

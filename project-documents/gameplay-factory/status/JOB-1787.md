# JOB-1787 — Storage audit

## Finding 1 — SURE
- **File and line:** `js/storage.js:41` on `gameplay/bug-list-1`.
- **What the player sees:** If the transfer entry fails to save while a separate career save is still waiting, closing the phone page can leave that career progress unwritten even if its save could have succeeded.
- **Why (original code):**
  ```js
  function flushPendingApplicationWrites(){const transferFlushed=typeof window.flushTransferDraftSave==="function"?window.flushTransferDraftSave():true;return transferFlushed!==false&&flushScheduledCurrentShowdownSave()!==false;}
  ```
  The `&&` skips the pending career save whenever transfer flushing returns `false`.
- **Smallest change:** Always attempt `flushScheduledCurrentShowdownSave()` and only then combine both results; preserve the false result when either save fails.
- **Confidence:** SURE.

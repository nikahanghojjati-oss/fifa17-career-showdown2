## Finding 1 · SURE · fixed

File and lines: `js/transferChallenge.js`, `updateTransferTimer` around lines 464–468; `initializeTransferChallenge` around lines 307–319.

What the player sees: with a live local Transfer Window, switching away from the browser tab can stop the one-second clock. Returning to the same tab leaves the timer frozen, and an expired window does not move to Guess Entry until another navigation or refresh.

Why: when a hidden-tab timer tick occurs, the interval stops:

```js
if(!currentShowdown || document.visibilityState === "hidden"){
    stopTransferTimerLoop();
    return;
```

Before the fix, this module had no corresponding `visibilitychange` listener to restart the timer when the tab returned.

Smallest change: install one visibility listener during Transfer Challenge initialization. On tab return, if the current season's Transfer Window is still active, restart the existing timer loop. Its established deadline check closes an expired window with `endedEarly: false`; no new timer rules, tap order, numbers, or player text.

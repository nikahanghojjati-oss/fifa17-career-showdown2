## Why
Switching screens used to flash the old design (white header, light page, old footer) for a moment before the Team V look appeared. A central fix is in PR #485 (branch `claude-gameplay/old-design-flash`). This job adds a test that fails if the flash comes back. It changes no game code.

## What to do
1. `git fetch origin gameplay/bug-list-1` and work from it. Add `tests/browser/v10-screen-flash-audit.cjs` and a `test:v10-flash` script in `package.json`. No other file changes.
2. Start the static server on port 4173 (`CMS_TEST_PORT=4173 node tests/support/static-server.cjs`), open `index.html` at 390x844 and at 1920x910, and set CDP `Emulation.setCPUThrottlingRate` to 4.
3. From Home, open Trophy Room, Legacy, Career Statistics and Rule Book (with `window.openOptionalModule(id)`), and the Settings overlay (click `#settingsButton`). Return to Home with `window.navigateTo('mainMenu')` after each.
4. On every `requestAnimationFrame` during each change, record the active screen (`getActiveScreenName()`), `document.documentElement.dataset.v10Screen`, and the computed background of `html`.
5. Fail if, while a screen that has a Team V look is shown, `data-v10-screen` is missing or the `html` background is `rgb(168, 189, 197)`. The test must pass on the head of PR #485 and fail on `gameplay/bug-list-1` before #485.
6. DEFAULT: if a screen will not open headless, skip it with a printed reason. Never pass silently.

## Why
Nik wants nothing from the old game to ever show. JOB-1635 (#680) stopped the old-design flashes, but the old stylesheets still exist and still load on demand through `js/optionalModules.js`: app.css, analytics.css, legacy.css, rulebook.css, settings.css, season.css, transfer.css, restore.css, offline.css, saveLibrary.css, remoteJoining.css, footballVisuals*.css and visual-fidelity-r3.css. Before any of them can move to `archive/old-design/`, we need to know which rules still style something on a live screen.

## Change (no app code changes)
1. Write `scripts/old-css-liveness.mjs`. For each sheet above: list every selector, then open the built site headless (as the existing browser audits do), visit every screen (use `tests/support/active-showdown-fixtures.cjs` for screens that need a showdown) at 393x660 and 1280x800, and record which selectors match at least one element on any screen.
2. Output `project-documents/gameplay-factory/reports/OLD_CSS_LIVENESS.md`: per sheet, the number of selectors, how many match live markup, the matching selectors (grouped by screen), and a verdict: DEAD (nothing matches), PARTLY LIVE, or LIVE. Also list which sheets `index.html` loads directly vs. which `optionalModules.js` loads, and note that `tests/contracts/v10-foundation-contracts.cjs` F10 pins `index.html` to r70 and caps startup gzip at 37495 bytes.
3. Do not move, delete or edit any CSS file.

## Why
Once Nik and Daniel play real games, every later release must still open every Showdown that older releases saved. Today the
reader accepts only the current save format (`js/sparkCompletedShowdownReader.js`, runtimeRevision checks), so a future format
change could hide real history. This job makes a permanent check that fails a release if old saved Showdowns stop opening.

## What to do
1. **Make fixtures from real saves on the emulator.** Using the CE2PG harness (copy it without committing:
   `git fetch origin gameplay/ce2pg && git show FETCH_HEAD:tests/browser/ce2pg-journey.cjs > tests/browser/ce2pg-journey.cjs`),
   play one finished 2-season Showdown and one finished 1-season draw on **live r75** (`origin/main`) and the same on this branch
   (r76). After each, export the emulator data (Firestore REST `GET .../documents` walk or `firebase emulators:export`) and keep
   only the documents of that finished Showdown plus both accounts' `careerIndex` docs. Save them as JSON under
   `tests/fixtures/saved-showdowns/r75-*.json` and `r76-*.json` with a README saying how they were made. Strip auth tokens; uids
   are emulator-only.
2. **The check**: `tests/firebase/saved-showdowns-still-open-emulator.cjs` loads every fixture into a fresh emulator (composed
   production Rules active), signs in as each manager, runs the real loader (`loadClosedShowdownCareer` /
   `readCompletedShowdown` / `buildCareerModel`) and asserts, per fixture: status completed, the winner, season scores, trophy
   counts and totals equal the values written in the fixture's README. It must also fail if any fixture is missing.
3. Register it with the release checks (same way as `tests/firebase/career-index-emulator.cjs`), and add one line to the release
   checklist file if one exists (search for "Release checklist").

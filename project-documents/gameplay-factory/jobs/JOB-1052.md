# JOB-1052 · Transfer Rules reject option ids and signing names the game cannot read (Olympiad V7)

**Held: needs Nik's approval for a Firestore Rules change.** Lowest priority: the UI cannot reach it, and only a hand-made write can.

**Lane:** Claude Sonnet worker run by the Team G lead.

## Bug
`firestore.transfer-challenge-production.fragment.rules:5` and `:212-222` accept any option id of 2-80 characters. The game's reader (`js/sparkSharedTransferChallenge.js:51-55`) accepts only catalog-shaped ids. A hand-made write could therefore leave a completed challenge that neither player can read.

## The change (only after approval)
- Tighten the Rules patterns to exactly what the reader accepts.
- Rebuild and re-pin the composed Rules (`tests/fixtures/composed-production-rules/`).
- Add emulator Rules tests that cover both accepted and rejected ids.
- Ship as a Rules deploy with the next release.
- Spark only, no billing.

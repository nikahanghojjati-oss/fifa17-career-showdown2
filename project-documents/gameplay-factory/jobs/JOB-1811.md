## The bug
Right after the Showdown closes, the final reconciliation panel and the FINAL SEASON cells on the Champion screen are
sometimes empty. CE2PG saw it in 4 runs on r74; it did not show in 3 runs on r75 (r75 cut most transactions), which is too few
to call it fixed. This job finds out whether it still happens and, if so, fixes it.

## What to do
1. Run CE2PG `CE2PG_SEASONS=3` with `CE2PG_RUN=1`, `2` and `3`, and `CE2PG_SEASONS=5 CE2PG_RUN=1` (one after another). Count
   empty final cells per run (the harness reports them in its final checks; also look at the Champion screenshots).
2. Read `js/productionSharedFinalReconciliation.js` and `js/sharedFinalReconciliation.js` (they own `#sharedFinalReconciliationPanel`),
   `js/seasonFinalV10.js:271` (moves the panels), and `js/productionSharedTerminalClose.js`. Look for a race: the panel is
   rendered before the final season's commit or the terminal record is read, and never re-rendered when it arrives.
3. If you reproduce it: write the failing test, fix it (re-render on the event the data arrives with; no timer, no poll),
   prove 4 clean runs.
4. If you cannot reproduce it in 4 runs: do not change code. Write the race analysis (the exact order of events that would
   leave the cells empty, with file:line) and a contract test `tests/contracts/final-cells-late-data-contracts.cjs` that
   simulates the late data in a vm sandbox. If that test fails on the base, fix the code it points at; if it passes, open the
   PR with only the test and the analysis.

## Proof required
The run table (run, empty cells yes/no) before and after; `node tests/browser/shared-final-reconciliation-audit.cjs` and
`node tests/browser/shared-terminal-close-audit.cjs` pass.

## Exact pointers (from Claude's standing-bug inventory of r75; confirm by reading)
From the bug inventory: `js/seasonFinalV10.js:30-38` fills `lastSeason` and `trophies` only inside the `p&&...acceptedSeasons===frame.seasonsPlayed` branch, i.e. only when a verified History projection with the same season count is cached. If the close lands first, the cells stay empty until something re-renders. That is the race to test in step 4.

| Lane | Can be typed | Writes |
| --- | --- | --- |
| GPT chat (GPT-6 Sol, normal chat, GitHub connector). Reading only. | Again and again until it says "0 left". Start after JOB-1814 has written some `SWEEP-*.md` files. | One file per bug on `factory/gameplay-v1` |

## What to do
1. On branch `factory/gameplay-v1`, folder `project-documents/gameplay-factory/status/`, read the `SWEEP-*.md` files and collect every
   row with verdict `STILL OPEN`. Number them in file order. Skip any that already has `project-documents/gameplay-factory/status/CARD-<sweep file>-<row>.md`.
   **Also (added 14 Oct):** read every `HUNT-*.md` file in the same folder and collect every finding row (confidence `HIGH` or
   `MEDIUM`). Their cards are named `CARD-HUNT-<slice>-<row>.md` (for example `CARD-HUNT-A07-1.md`). Do the sweep rows first, then
   the hunt rows in slice order. Several hunt rows describe the same bug (for example the tied CAREER TABLE rank appears in more
   than one slice): if a row is the same bug as a card that already exists, write its card with verdict
   `DUPLICATE OF <card name>` and one line why, and nothing else.
2. Take the next **2** and, for each, open the cited file on branch `gameplay/bug-list-1` (today's code) and write a bug card:
   - **Title** in game words; **what the player sees** (one or two sentences); **where** (file:line today, quote 1-5 lines);
   - **why** (the logic error in plain words); **how to reproduce** (taps or a node call with inputs and the wrong output);
   - **the failing test to write**: file name `tests/contracts/sweep-<short-name>-contracts.cjs`, the inputs, the expected
     result, the wrong result today; which existing test file to copy the sandbox pattern from;
   - **smallest fix** (describe it; no code over 10 lines); **risk** (what else uses this code; search the repo for callers and
     list them); **lane**: `Work mode` (logic + contract test), `Codex` (needs a browser), or `Claude` (online records, sign-in,
     pairing, rules); **size**: S (< 20 lines), M, L.
   - If, after reading today's code, it is NOT a bug, write the card with verdict `NOT A BUG` and why.
3. Write `CARD-<sweep file without .md>-<row>.md`, push it, then the next.

## Done
One line per card: `CARD <name>: <lane>, <size>.` then `<k> cards left.` Game words only. Never ask to continue.

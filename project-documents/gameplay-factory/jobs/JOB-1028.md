## The bug
A career whose only Showdown was abandoned has zero totals. Shared analytics then correctly sends `bestSeasonScore`, `averageLeaguePoints` and `averageLeagueGoals` as `null`. In `js/careerScreensV10.js`, `v10CareerStatistics` passes those fields to `v10Pick`, which requires every field to be a finite number, so the whole Statistics screen shows "unavailable". Trophy Room shows the same career as ready with zeros.

## The exact change (one file: `js/careerScreensV10.js`)
In `v10CareerStatistics`, replace
`managers[manager]=v10Pick(model.managers[manager],CS_FIELDS);`
with
```js
      // JOB-1028 (H1019-5): an abandoned-only career has no best season or averages yet; show 0 like the old Statistics screen.
      const csRecord=model.managers[manager]&&{...model.managers[manager]};
      if(csRecord)for(const key of ["bestSeasonScore","averageLeaguePoints","averageLeagueGoals"])if(csRecord[key]===null)csRecord[key]=0;
      managers[manager]=v10Pick(csRecord,CS_FIELDS);
```
Change nothing else. Keep `v10Pick` strict (a `null` careerPoints must still make the frame unavailable; a contract checks that).

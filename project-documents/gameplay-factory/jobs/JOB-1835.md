## Why
PR #862 (JOB-1828, contains JOB-1812 / #842) moves the free-limit notice into #mainMenu so it no longer covers the phone
soundtrack controls or shows under Connect Players. The JS is right. But the one new CSS rule, `css/homeV10.css:7`
`grid-area: 1 / 1`, makes the notice a grid item of #mainMenu. The landscape grid is `minmax(0,1fr) var(--phone-nav)`
(homeV10.css:1147) with `.nav-reserve` in `grid-row: 2` (:1164), so `.phoneHeroGrade` drops into a new third row. Measured:
740x360 rows `304px 56px` become `181px 56px 123px` (the dark nav-reserve strip moves from y=304 to y=181); 844x390
`334px 56px` become `206px 56px 128px`. A dark band covers Trophy Room / Rule Book / Settings and the CAREER MODE wordmark.
The PR's audit passes because it only compares button rectangles. Full report: `/mnt/project-files/gameplay/r76/verify/PR-862.md`.

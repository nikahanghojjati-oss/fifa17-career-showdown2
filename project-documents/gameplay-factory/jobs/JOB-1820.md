## Why
The code that loads at startup is capped at 37,495 gzip bytes (checks: `tests/contracts/final-polish-presentation.cjs`,
`v10-club-contracts.cjs`, `v10-transfer-contracts.cjs`, `reus-gate-startup-contracts.cjs`,
`browser-journey-emulator-switch-contracts.cjs`, `static-app-release-contracts.cjs`). The base uses 37,484, so 11 bytes are free.
JOB-1805 (PR #843) is a correct fix for the "Season 1 of N" label that adds 85 bytes to `js/menuExperience.js` and
`js/showdownUI.js`, so it fails those 6 checks. Other r76 fixes may need room too. Claude will free the room on Thursday night;
this job finds the safest candidates and measures each one, so Claude only has to pick and apply.

## What to do
1. Start from `gameplay/bug-list-1`. Run `node tests/contracts/final-polish-presentation.cjs` and copy its "raw / compressed" line.
   Read the test to learn exactly which files count as startup (it builds the list from `index.html`).
2. For every startup file, record its raw and gzip size (largest first).
3. Find at least 8 candidates that would save bytes **without changing what the game does or how it looks**. Good kinds:
   - a function, constant or branch that nothing calls (prove it with `rg` across `js/`, `css/`, `index.html`, `shared/` and `tests/`);
   - code that only runs after a click or after Home is shown and could move to a file that already loads later
     (name that file and the hook that would call it);
   - a long string, comment block or repeated literal in a startup JS or CSS file.
4. For each candidate, apply it **locally only**, re-run the size test, write down the real gzip saving, then undo it.
   Also run `npm run -s test:contracts` with the candidate applied and note pass or fail.
5. Rank the candidates by (saving ÷ risk). Mark risk Low, Medium or High and say why in one line.

## What to do
1. Work on the PR's own branch `codex/job-1843`. It is `gameplay/clean-start` plus one empty start commit.
2. Copy the harness without committing it:
   `git fetch origin gameplay/ce2pg && git show FETCH_HEAD:tests/browser/ce2pg-journey.cjs > tests/browser/ce2pg-journey.cjs`
3. Install with `npm ci`. Then check that `node_modules/firebase/` exists at firebase@12.17.0; if it doesn't, run
   `npm install --no-save --package-lock=false firebase@12.17.0`.
4. Start the server and the run in **one** shell command, so the server is still alive when the run starts. (In the first try the
   server had stopped before the browser opened.)
   `(nohup env CMS_TEST_PORT=4511 node tests/support/static-server.cjs > /tmp/srv.log 2>&1 &) ; sleep 3 ; curl -sf http://127.0.0.1:4511/ > /dev/null && CE2PG_SEASONS=1 CE2PG_RUN=1 CMS_BASE_URL=http://127.0.0.1:4511/ node tests/browser/ce2pg-journey.cjs`
   The harness starts the Firebase emulators itself with `npx firebase-tools@15.28.1` (Java 17+), on a demo project only.
5. If you cannot push (no GitHub credentials), skip the commit. Put the whole report from step 6 in your reply comment instead.
6. Write `project-documents/reports/JOB-1843.md` with these sections:
   - the branch sha;
   - the verdict;
   - checks passed out of total;
   - every failed check id with its one-line reason;
   - the run time.

   If you can push, commit only that file to `codex/job-1843` and push it.

If a small detail doesn't fit (a port is busy, a path differs), do the closest safe thing, note it in the report and keep going.

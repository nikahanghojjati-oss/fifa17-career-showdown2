## Why
The screen-fix jobs for the club group (Sol chat, queue items) cannot run a browser. This job gives them real numbers: where, at which window size, something overflows, overlaps or is cut off. It changes no game file.

## What to do
1. `git fetch origin gameplay/bug-list-1` and work from it. Find how the existing browser audits in `tests/browser/` open the game and reach a screen with test data (look for one that already visits club packs); reuse that approach, do not change those files.
2. For each of these ten window sizes, open every club screen state you can reach and measure: 360x640, 390x844, 430x932, 844x390, 932x430, 768x1024, 1280x650, 1366x768, 1920x1080, 2560x1080. Record, per size: horizontal scrollbar yes/no, any element wider than the window, any control smaller than 44 px on touch sizes, any text clipped (scrollWidth > clientWidth), and whether the main action button is inside the first screenful.
3. Write one file `project-documents/gameplay-factory/queue/results/measure-club.md`: a table (size, screen, problem, selector, measured value) and a short "most important five" list. Save the script you used as `project-documents/gameplay-factory/queue/results/measure-club.cjs`.
4. DEFAULT: if you cannot reach a screen, say so in the report and measure the ones you can. Never edit `css/v10Club.css`, `js/clubScreenV10.js` or any other game file.

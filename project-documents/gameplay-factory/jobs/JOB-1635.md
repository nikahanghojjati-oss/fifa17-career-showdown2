## The goal, as checks a test can prove
1. **No old-game frame, ever.** On every screen change (Home → each screen → Home, the Setup flow, Season Results, Final Winner, Settings overlay, Rule Book, Trophy Room, Legacy, Career Statistics, Rivalry), no animation frame shows the old design. That means none of these:
   - the old white header
   - the light page `rgb(168, 189, 197)`
   - the old footer
   - the old fonts
   - an unstyled screen
   - a screen without `html[data-v10-screen]` while Team V's look is registered for it
2. **No half-loaded pictures.** A screen's main artwork never paints at low resolution or half-decoded in front of the player. Decode it (`img.decode()` / preloaded `Image`) before the screen is revealed, or reveal behind a short fade that only starts once it's ready.
3. **One smooth transition system.**
   - Every screen change uses the same short transition (about 150–250 ms crossfade or slide, matching Team V's look), driven from one place (js/v10Screens.js), not per screen.
   - The new screen is ready (styles applied, key images decoded) before it becomes visible.
   - No double animations, no jump when the scroll position resets, and `main` stays the only scroller.
4. **Taps feel right.**
   - Every button gives instant press feedback (under 100 ms) with no layout shift.
   - A second tap during a transition never starts a second navigation or a double write.
5. **Motion settings work.**
   - Settings › Motion has FOLLOW DEVICE (default), FULL and REDUCED (see js/settings.js around "FOLLOW DEVICE").
   - FOLLOW DEVICE must follow `prefers-reduced-motion` live.
   - REDUCED means no slides, parallax or scale: an instant swap or a ≤100 ms fade only.
   - FULL is the smooth transition above.
   - Today REDUCED is closer to right than the default, so check the default path first.
   - Lighting and atmosphere effects must also respect it.
6. **Old design out of the load path (archive, never delete).**
   - Every old-design stylesheet or script no current Team V screen needs moves to `archive/old-design/` and is removed from index.html and the service-worker shell list.
   - Files known to be still loaded: app.css, analytics.css, legacy.css, rulebook.css, settings.css, season.css, transfer.css, restore.css, offline.css, saveLibrary.css, remoteJoining.css, footballVisuals*.css, visual-fidelity-r3.css. visual-fidelity-r2.css is already unreferenced.
   - Prove each one is unused first: grep its selectors against live markup and Team V's files, and check it in the browser. Rules a live screen still needs move into that screen's `css/*V10.css` glue file.
   - If a file is still needed by an offline/restore path, leave it loaded only on that path and say so.
7. **Old cached builds.**
   - Check that the service worker can never serve an old build's HTML, CSS or JS mixed with the new one (stale shell after an update).
   - Old caches must be deleted on activate, and the shell must be versioned together.
   - Keep the current update model: no forced skipWaiting; the Update button still works.

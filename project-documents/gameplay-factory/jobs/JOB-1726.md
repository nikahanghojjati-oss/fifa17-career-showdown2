## What to build
A small player quality-of-life fix, chosen by Nik. It is a logic fix that one new contract test can prove, so no pictures and no browser are needed. There is no read limit: read the files you need.

**Today:** If one gameplay module fails to start, the next try re-runs the modules that already started, so a tap could fire twice.
**Change:** Remember which starters finished and skip them on retry; screens and taps stay as they are.
**Evidence (check it first, line numbers may have moved a little):** `js/optionalModules.js` lines 156-175 (the done flag is set only after the whole loop); audit PR #732 (JOB-1671, PROBABLE).
**How to prove it:** a Node test with a failing second starter: after a retry the first starter must have run exactly once and the second must run again.

Keep every screen, tap order, rule and number exactly as it is. Presentation and behaviour only as described. Use gameplay words only.

# JOB-1039 · Legacy stops reloading on every shared event and never spins forever

| Lane | Depends on | Branch to start from | PR into |
| --- | --- | --- | --- |
| Codex cloud (escalate: Claude Sonnet) | none (independent of 1037: different file) | `gameplay/bug-list-1` | `gameplay/bug-list-1` |

## What players see (live r63)
Legacy (Legacy Archive tab) can sit on "Loading your Showdown history…" forever on a phone.

## Root cause (verified on the emulator)
`js/rivalryLegacyV10.js` ~132 calls `refresh()` on **every** history-convergence and terminal-close state event. `refresh()` sets the LOADING frame first (~168) and throws away any load that a newer one replaced (~176). With a finished-but-unclosed Showdown current, the lead counted 15-24 full career loads in 9 seconds while Legacy was open. On a phone, a load that takes longer than the gap between events never finishes, so the spinner never clears, and every load spends Firestore reads.

## The change (one file: `js/rivalryLegacyV10.js`)
- Once a ready or partial frame has been shown, never go back to the LOADING frame. Keep showing the last frame while a reload runs, then swap in the new one.
- Ignore a state event whose phase/status did not change since the last one handled.
- Share one in-flight load: if a load is running, do not start another. At most one follow-up load runs after it finishes, if a relevant event arrived meanwhile (trailing coalesce, minimum 2 seconds apart).
- A load that fails or times out (15 s) shows the existing unavailable frame with the retry, never an endless spinner.
- Keep the public API (`mount`, `refresh`, and whatever `js/careerScreensV10.js` and `js/legacy.js` call) unchanged.

## Proof
New contract `tests/contracts/legacy-refresh-contracts.cjs` (node, no browser; stub the loader and the event sources like `tests/contracts/hunt-1019-restore-career-contracts.cjs` does):
(a) 20 state events in 1 s → at most 2 loads;
(b) after a ready frame, a reload never renders LOADING;
(c) a loader that never resolves → unavailable frame after the timeout;
(d) events with an unchanged phase → no load.
Run `node tests/contracts/legacy-refresh-contracts.cjs` and `npm run -s test:contracts`.

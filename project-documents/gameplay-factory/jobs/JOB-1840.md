## Why
Nik's owner decision (16 Oct): before the first real game, Nik and Daniel each press one button once. From then on History, Career
Statistics, Trophy Room, Legacy and Rivalry Statistics count only Showdowns created after that press. Old test Showdowns stay in
Firebase untouched (nothing is ever deleted), and the marker can be switched off again to show them.

## What to build (failing tests first, then the code)
1. **Data**: one new document per account, `accounts/{uid}/careerStart/current`, using the standard envelope (copy how
   `careerIndex/current` is written in `js/persistentNikDanielPair.js`: schemaVersion 1, objectType `careerStart`, objectId
   `current`, revision, contentHash, lifecycleState `live`, updatedBy fields, tombstone null). `data` has exactly two keys:
   `hiddenRivalryIds` (the account's career-index rivalry ids at the moment of the press, oldest first) and `active` (boolean).
2. **Rules** (`firestore*.rules` inputs, then rebuild with `scripts/build-production-firestore-rules.mjs` and
   `scripts/build-production-firestore-rules-with-persistent-pair.mjs`): only the account owner, on an active device, may get,
   create or update it. Create: `active == true` and `hiddenRivalryIds` equals `careerIndex/current`'s `data.rivalryIds` exactly
   (empty list allowed when there is no index yet; refuse create when `sealedPageCount > 0`). Update: CAS envelope (revision +1),
   only `active` may change; `hiddenRivalryIds` never changes. list and delete: false. Change no existing rule.
3. **Readers**: `js/sparkClosedShowdownCareerLoader.js` reads the marker once per load (cache it like the index) and, when
   `active`, skips every id in `hiddenRivalryIds`. Rivalry Statistics must also skip a hidden newest Showdown. Missing marker
   = today's behaviour, byte for byte.
4. **Button**: Settings gets one row, `START REAL CAREER`, with a confirm step: "Start your real career now? Finished test
   Showdowns stay saved but are hidden from History, Trophy Room and Legacy. Ask Daniel to press this too." Hidden while a Showdown
   is active (unfinished). After pressing it shows `REAL CAREER STARTED <date>` and a small `SHOW TEST SHOWDOWNS AGAIN` that
   sets `active=false` (and back). Use the existing Settings row styles; no new pictures, no dimming or overlays.

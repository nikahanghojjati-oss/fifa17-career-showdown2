## The bug
On a phone (393x660 and 393x852 portrait), the Trophy Room does not show the manager ranks or the all-time records, and the
**MORE** sheet's "CAREER DETAILS" is empty. On desktop the same data shows correctly. CE2PG flagged it in every run on r74 and
r75 (it is the only history check that fails on r75). This is missing data, not styling.

## Where to start
`js/trophyRoom.js` (the data model, e.g. `trophyRoom.standings`) and the V10 glue `js/careerScreensV10.js` (`v10Ranks`, around
lines 35-65). Team V's screen files under `visual-assets/v10_1/` are FROZEN (never edit). Find where the phone layout
builds the MORE sheet and the ranks/records sections, and why it renders them empty or hidden: a phone branch that never fills
them, a container the data is written to that the phone layout does not show, or a filter that drops them.

## Rules for this job
Fill or show the existing phone sections with the same data desktop shows. Do NOT redesign: no new sections, no new styling,
no size or colour changes. If the only way is a CSS change that makes a hidden phone section visible, it must be the smallest
rule (one selector) and you must attach before/after phone screenshots; write "visual change: <selector>" in the PR body so
Claude checks it with Nik's design rules.

## Test to add (must fail on the base)
`tests/browser/phone-trophy-room-data-audit.cjs`: seed a finished Showdown the way `tests/browser/shared-history-convergence-audit.cjs`
does (or local history like the existing Trophy Room audits), open the Trophy Room at 393x660, open MORE, and assert the
ranks, the all-time records and CAREER DETAILS contain the same figures as the desktop view at 1920x1080.

## Proof required
New audit fails on the base, passes after; `CMS_CHROMIUM_MULTI_CONTEXT=1 node tests/browser/v10-screen-flash-audit.cjs` passes;
CE2PG 3-season run: the phone Trophy Room history checks pass.

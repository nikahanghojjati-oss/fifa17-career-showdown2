## What happens now (seen on the emulator, 10 Oct)
A manager taps **CONTINUE TO SHARED SEASON RESULTS**. Loading the results takes a few seconds. Meanwhile the manager goes to another screen (for example the dashboard). When the slow load finishes, the game jumps them back to Season Results, overriding the screen they chose.

## The fix (one file)
In `js/productionSharedSeasonResults.js`, function `pssrOpen`:
1. At the start of `pssrOpen`, read the current navigation number: `const navAtTap=typeof root.getNavigationRevision==="function"?root.getNavigationRevision():null;` (the same helper `js/optionalModules.js` lines 467-482 already uses).
2. Just before `await root.navigateTo("seasonEntry")`, if `navAtTap!==null` and `root.getNavigationRevision()!==navAtTap`, return `false` without navigating (the manager moved on; their newer choice wins).
- DEFAULT: keep every other line of `pssrOpen` exactly as it is. No text, tap order or scoring change.

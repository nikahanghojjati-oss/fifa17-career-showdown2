## The bug
In multi-season shared runs, pressing **BACK TO SHOWDOWN HOME** (on Season Results / the Champion screen / Rivalry Statistics /
Career Statistics) sometimes opens the dashboard screen instead of Home (`#mainMenu`). CE2PG saw it in every multi-season run;
the "smart back" logic seems to return to the previous screen instead of Home.

## Where to start
- `js/statistics.js:80` sets the button text; follow its click handler.
- `js/seasonFinalV10.js` (the Champion screen exits, around lines 1439-1727) and `js/productionSharedSeasonResultsRoute.js`.
- Search `js/` for the smart-back / previous-screen logic (`showScreen(`, `previousScreen`, `history`, `data-route`).
The rule the player expects: a button that says "BACK TO SHOWDOWN HOME" always opens Home (`#mainMenu`); a button that says
"BACK" may return to the previous screen.

## Test to add (must fail on the base)
`tests/browser/back-to-showdown-home-route-audit.cjs` (browser audit, not registered): open the game, reach each screen that
has a "BACK TO SHOWDOWN HOME" button through the real taps where possible (or the same `showScreen` calls the existing audits
use, e.g. `tests/browser/persistent-pair-user-facing-routing-audit.cjs`), first visiting the dashboard so it is the "previous
screen", press the button, assert the active screen is `mainMenu`. Print one line per screen. Use the patterns from
`tests/browser/stability-audit.cjs` to start Chromium.

New audit fails on the base and passes after. Also run `node tests/browser/persistent-pair-user-facing-routing-audit.cjs`,

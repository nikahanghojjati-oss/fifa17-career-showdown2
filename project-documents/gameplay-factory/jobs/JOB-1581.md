## Why
L3 (storage, visual, gameplay) is the slowest lane at about 9.4 minutes; the next is L4 at 7.1. Splitting L3 makes the Gate finish about 2 to 4 minutes sooner with every check still run.

## Change
1. Split `l3-storage-visual-gameplay` into `l3a` (storage + gameplay groups) and `l3b` (visual group), each computing its own route with `node scripts/showdown-gate.mjs route --lane L3A|L3B`. Every proof id L3 runs today must be run by exactly one of the two; add both to `LANES` and to the seal's required lanes.
2. Cache the Playwright browser download and the `npx firebase-tools` package in every lane that installs them (`actions/cache` pinned by SHA like the existing ones; keys include the pinned versions).
3. Tests (add only): the coverage contract asserts the union of L3A and L3B proof ids equals the old L3 set for the full route and for a visual-only route, with no id in both.

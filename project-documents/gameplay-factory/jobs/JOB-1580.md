# JOB-1580 · Showdown Gate: run the L5 lane only when its inputs changed

| Lane | Depends on | Branch to start from | PR into |
| --- | --- | --- | --- |
| White team: Codex default coding model, High effort (Codex cloud, this repo) | none | `gameplay/bug-list-1` | `gameplay/bug-list-1` |

## Why
Every PR runs L5 (`tests/firebase/composed-production-rules-regression.cjs`, about 4 minutes) even when the change is one CSS file. L5's result depends only on its inputs, so when none of them changed on a PR the base branch's green L5 already proves it. Nik wants faster checks with no test dropped (POS20: never reduce a deterministic test, so the test still runs whenever an input changes, and always on pushes and on every PR into main).

## Change
1. In `scripts/showdown-gate.mjs` add `export const L5_INPUTS` (glob list) and `export function l5Affected(files)`. Inputs: `firestore*.rules`, `firestore.*.fragment.rules`, `firebase*.json`, `scripts/*firestore*`, `scripts/*rules*`, `scripts/inject-persistent-pair-rules.mjs`, `tests/firebase/**`, `tests/rules/**`, `data/transferOptions.js`, `package.json`, `package-lock.json`, `.github/workflows/showdown-gate.yml`, `scripts/showdown-gate.mjs`. When unsure whether a file feeds L5, include it.
2. `route --lane L5` outputs `l5_run=true` when the event is not `pull_request`, OR the PR base ref is `main`, OR `l5Affected(changedFiles)`; else `l5_run=false` plus `l5_reason` naming why.
3. In `.github/workflows/showdown-gate.yml` L5: gate the Java, cache, install and regression steps on `steps.route.outputs.l5_run == 'true'`. The lane still runs, records its route and uploads its lane record, so the seal sees it.
4. The seal accepts L5 as green only if (a) the regression ran and passed, or (b) its lane record says `l5_run=false` AND the seal's own independent recompute of `l5Affected` on the same files also says false. Anything else fails closed.
5. Tests (add only): in `tests/contracts/showdown-gate-watchdog-contracts.cjs` or a new `tests/contracts/showdown-gate-l5-inputs-contracts.cjs`: a CSS-only diff → false; each input family → true; push event → true; base `main` → true; seal rejects a skipped L5 whose files include an input.

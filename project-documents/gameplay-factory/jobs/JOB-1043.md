## Problem (verified on main e49add99)
`showdown-gate.yml` job `l1-core` elevates to `actions: write`, checks out the PR head with persisted credentials, and runs `scripts/gate-preempt.mjs` from that checkout. Pull-request code therefore runs with an Actions-write token.

## Change
- Remove L1's `permissions` elevation and its preempt step. The trusted Physio (`gate-watchdog.yml`, default-branch checkout, `persist-credentials: false`) keeps the preempt sweep.
- Set `persist-credentials: false` on every Gate checkout.
- Make the Gate coverage contract and `tests/operations/pos10-authority.test.mjs` enforce the stricter rule (no write anywhere in the Gate, no preempt in the Gate, no persisted credentials). No test is loosened.

## Proof
`node tests/contracts/showdown-gate-coverage-contracts.cjs`, `node tests/contracts/showdown-gate-physio-contracts.cjs`, `npm run -s test:contracts`, `npm run -s test:ops`. Then the PR's own Gate L1 log must show `Actions: read`.

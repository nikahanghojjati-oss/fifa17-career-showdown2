## The bug (already fixed once, correctly)
In a two-player Showdown, the CONTINUE CAREER tile on Showdown Home and the dashboard header keep saying "Season 1 of N" after
season 1. JOB-1805 (PR #843, commit `b1cbb27c6`) fixed it in `js/menuExperience.js:181` and `js/showdownUI.js:350-359` by asking
`window.CareerModeProductionSharedMultiSeasonProgression.resolveSeason(...)` for the real season when the Showdown is shared.
Its new test `tests/contracts/shared-season-chip-contracts.cjs` passes 5/5. **The logic is right. Keep it.**

## Why it failed
The code that loads at startup is capped at **37,495 gzip bytes**. The base (`gameplay/bug-list-1`, release r75) uses 37,484.
PR #843 adds 85, so it reaches 37,569 and these 6 checks fail: `tests/contracts/final-polish-presentation.cjs`,
`v10-club-contracts.cjs`, `v10-transfer-contracts.cjs`, `reus-gate-startup-contracts.cjs`,
`browser-journey-emulator-switch-contracts.cjs`, `static-app-release-contracts.cjs`.
**Never raise the limit and never edit those tests.**

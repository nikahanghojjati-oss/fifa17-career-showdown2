## The bug (two parts)
1. **Route.** CE2PG found no player path to Rivalry Statistics: `#rivalryStatisticsButton` is hidden on purpose by
   `css/app.css:220` (`#rivalryStatisticsButton:not([data-test-surface=internal-audit]){display:none!important}`) and the
   Career Stats rivalry button is hidden too. The Rivalry Statistics screen itself exists (markup in
   `js/rivalryLegacyV10Markup.js`, key `rivalryStatistics`; back button `#rvBack`).
2. **Data.** Opened by script, it stays on "Loading rivalry statistics…" mid-Showdown and shows nothing after the close.

## What to do
Part 1 is a real bug, found by reading: the Career Statistics screen HAS a "current rivalry statistics" button, but it is
always hidden because `js/careerScreensV10.js:1337` checks `root.currentShowdown`, while `currentShowdown` is a script-scoped
`let` in `js/showdown.js:1` (never a window property), so the check is always false. The right check is
`typeof currentShowdown !== "undefined" && currentShowdown` (confirm `careerScreensV10.js` runs as a classic script sharing that
scope; if not, read it through whatever accessor `js/showdown.js` exposes). Also, after a Showdown closes,
`openRivalryStatistics()` returns early at `js/statistics.js:623` because `currentShowdown` is null: decide from the code whether
the closed Showdown's figures should still open (they should, from the completed Showdown the Career screens already read) and
fix that path. Leave `css/app.css:220` (it hides an old, different button) as it is. Write a table in the PR body: screen,
element, visible before/after at 1920x1080 and 393x660.
Part 2 is a fix: the text "Loading rivalry statistics…" is in `visual-assets/v10_1/rivalry-statistics/strings.json`, shown by
Team V's module `visual-assets/v10_1/rivalry-statistics/rivalry-statistics.js` when its data is not ready. That folder is FROZEN
(never edit it); the glue that feeds it is `js/rivalryLegacyV10.js` (plus `js/statistics.js` and the shared readers it calls).
Find what the glue waits for, and make it show the right figures mid-Showdown and after the close, from the data the game already has. No
new timer or poll.

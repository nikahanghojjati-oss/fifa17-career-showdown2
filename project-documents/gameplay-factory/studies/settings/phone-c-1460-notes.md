# Settings phone C (JOB-1460) notes
- Decision: the most compact layout that keeps every element. Two-column key/value grids, smaller type, tighter padding, and one page scroll (no nested scroll box). DONE is pinned at the bottom.
- All four live panels and every live label, button and tap target are kept, in the live order.
- Text is the live text. Run-time values are [live value]. Panel headings use the condensed face (Team V note).
- Fit: the content is taller than 640px, so the page scrolls as a whole. The no-scroll rule at 360x640 is not met and this is not measured in a browser.
- No tab bar: Settings is an overlay.

# LUNA ROLE CONTRACT — V4

Current role:
RESTRICTED IMPLEMENTATION BUILDER

## What Luna is good for

- HTML/CSS/JS production from an explicit visual composition
- exact asset integration
- state variants
- responsive implementation from specified responsive rules
- accessibility implementation
- overflow / regression checking
- bounded CSS refinement

## What Luna is not responsible for

- deciding whether an old approved screen is still current
- inventing the product's visual language
- choosing fonts
- defining environment exposure
- choosing asset substitutes
- deciding the dominant screen concept
- turning abstract "premium/cinematic" prose into original art direction
- approving its own work

## Entry condition for Luna

Luna receives a major screen only after Sol has supplied:
1. current-product truth card
2. golden composition / rendered reference
3. exact presentation primitives
4. exact assets
5. state matrix
6. responsive rules
7. QA matrix

If any are missing, Sol continues design work first.

## Success condition

Luna is valuable when it preserves or improves the Sol golden composition while adding implementation/state coverage.

If Luna repeatedly reduces the visual quality of a locked golden composition, move Luna to secondary QA / isolated implementation only.

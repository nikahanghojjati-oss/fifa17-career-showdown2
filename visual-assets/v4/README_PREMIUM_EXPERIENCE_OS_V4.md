## Owner correction now encoded as law

Previously approved Home, League and Club Assignment visuals are NOT finished screens.

They are reference material for visual DNA only.

Every screen must be re-audited against the current live product because product behavior, controls, states, modules and connected-play surfaces have changed.

No screen is considered current merely because its old visual composition was approved.

## V4 mission

Make Career Mode Showdown feel designed by an experienced senior product designer / creative developer rather than assembled screen-by-screen.

Premium quality means:
- one coherent art direction across the entire product;
- screen-specific cinematic storytelling;
- current product truth;
- disciplined typography and spatial rhythm;
- depth, layering, lighting and material hierarchy;
- custom visual composition rather than generic rectangles;
- responsive recomposition, not shrinking;
- purposeful motion;
- accessibility and performance;
- precise states and microcopy;
- consistent components without making every screen look identical.

## Research synthesis

V4 is informed by:
- Apple HIG: purpose, familiarity, simplicity, craft and delight; hierarchy should make importance obvious; motion should be purposeful and brief.
- Figma design-system guidance: define typography, elevation, grids, spacing and responsive layouts as a connected system rather than independent styling choices.
- Webflow University visual-developer curriculum: reusable classes, scalable design systems, responsive layout, interactions, accessibility and pre-publish quality review.
- Awwwards Academy curriculum themes: art direction, flawless typography, purposeful motion, memorable interactive UI and design leadership.

The lesson is not "add more effects."

The lesson is: premium work comes from intentional hierarchy, consistent foundations, a strong concept, systematic craft, and iterative visual critique.

## V4 architecture

V4 has five authorities:

1. LIVE PRODUCT MAP
   Current repository / runtime decides what exists and how it behaves.

2. VISUAL LANGUAGE
   V3 presentation primitives define shared world, typography, material, shell and character staging.

3. CINEMATIC COMPOSITION
   Sol creates a screen-specific golden composition before implementation is delegated.

4. IMPLEMENTATION
   Luna productionizes the approved composition and required states without inventing a new visual language.

5. PREMIUM QA
   Sol compares the browser render against both the current product contract and the premium quality bar before owner review.

## Definition of done

A screen is done only when BOTH are true:

CURRENT
It reflects the latest live product state, controls, copy, navigation, privacy and behavior.

PREMIUM
It passes the Premium Quality Bar V4 and visibly belongs to the same cinematic product family.

Old approval alone satisfies neither condition.

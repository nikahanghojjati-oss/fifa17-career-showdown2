# SHOWDOWN VISUAL — PREMIUM DESIGN LAWS V5

These are Sol's mandatory design laws for major screens.

## LAW 01 — DESIGN THE SCENE BEFORE THE COMPONENTS

First solve:
- what the player sees first;
- what the player feels;
- where the eye travels;
- what action resolves the scene.

Only then build controls.

## LAW 02 — ONE DOMINANT OBJECT

Every Level-A screen needs one unmistakable visual center.

Examples:
- Home: rivalry headquarters / current-showdown command focus
- League: wheel
- Club: reveal packs
- Transfer: operations / guess board
- Results: confrontation / score adjudication
- Summary: outcome / resolution

If five cards compete equally, the composition failed.

## LAW 03 — THE WORLD MUST BE VISIBLE

For cinematic screens, the environment cannot be technically present but optically erased.

Minimum requirement:
a blurred thumbnail of the screen should still read as a football/stadium world.

## LAW 04 — NO BOX BY DEFAULT

A container is earned only when it does one of these:
- groups interaction;
- creates an elevation plane;
- protects readability;
- represents a real object/module.

Prefer:
- spacing
- alignment
- rules
- layering
- lighting
- asymmetry
- clipped surfaces
before adding another rectangle.

## LAW 05 — TYPOGRAPHY IS PRODUCT IDENTITY

Use four roles only:
- DISPLAY
- FUNCTIONAL
- BODY
- PERSONALITY

No screen invents a fifth role.

Display typography may be expressive.
Functional typography must be highly legible.
Personality type is rare and never used for controls.

## LAW 06 — USE A SPACING RHYTHM

Base rhythm:
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96

Rare optical nudges may exist, but layout should not be composed from arbitrary unrelated numbers.

## LAW 07 — USE A CONSISTENT LIGHT MODEL

Every screen defines:
- primary light direction
- environment exposure
- rim-light side
- panel highlight edge
- shadow direction
- gold bloom intensity

Characters and UI should appear to occupy the same illuminated world.

## LAW 08 — GOLD IS SCARCE

Gold communicates hierarchy.

Priority:
1. primary CTA / active state / dominant object
2. title emphasis / selected item
3. thin rails / decorative accents

If every border is gold, gold has no meaning.

## LAW 09 — DEPTH HAS THREE TO FIVE PLANES

Typical Level-A screen:
1. stadium/world
2. atmosphere/light
3. characters/environmental props
4. dominant interactive object
5. chrome/status overlays

Flattening all five into one dark panel is prohibited.

## LAW 10 — RESPONSIVE MEANS RECOMPOSE

Desktop -> tablet -> mobile is not scale().

On mobile:
- suppress nonessential hero art;
- preserve world/brand through crop, light, texture and typography;
- reorder around the task;
- maintain labels/context;
- preserve the primary action.

## LAW 11 — MOTION MUST EXPLAIN SOMETHING

Motion must do at least one:
- indicate transition;
- confirm action;
- transfer attention;
- reveal state;
- celebrate completion.

Otherwise remove it.

## LAW 12 — OPTICS BEAT PURE MATH

Use mathematical grids as a foundation, then perform optical review:
- perceived centering;
- title weight;
- character balance;
- uneven visual mass;
- edge tension.

## LAW 13 — CURRENT PRODUCT TRUTH WINS

Old approved composition is not authority when product behavior changes.

Re-read current source before every redesign slice.

## LAW 14 — BUILD THE GOLDEN FRAME BEFORE DELEGATION

Sol must create and render the first premium composition.

Luna does not receive a major screen until the golden frame demonstrates the intended quality.

## LAW 15 — PREMIUM QA IS VISUAL + PRODUCT

A beautiful wrong screen fails.
A correct ugly screen fails.

Both gates must pass.

## LAW 16 — AI-SMELL TEST

Reject if the first impression contains several of:
- equal rounded cards
- repeated generic boxes
- arbitrary gradients
- gold border on everything
- dark empty void
- default form layout
- unrelated font changes
- centered-everything composition
- pasted-on characters
- overused glow
- fake decorative data
- random 12–16px radii everywhere
- huge unexplained dead zones

## LAW 17 — SCREENSHOT TESTS

Every major candidate is reviewed with:
- 2-second hierarchy test
- blur/silhouette test
- grayscale hierarchy test
- typography-only test
- background-only test
- box-count test
- mobile context test
- focus/contrast test

## LAW 18 — BEAUTY CANNOT MASK PRODUCT FLAWS

The aesthetic-usability effect is real enough to require discipline.

Always run product/state QA separately after visual approval.

# PREMIUM VISUAL SCORECARD V5 — 100

This evaluates the screen, not the model that built it.

## Hard gates

G1 Current product truth
G2 Unified typography
G3 Environment visible and intentional
G4 Screen-specific dominant concept
G5 No generic AI/SaaS composition
G6 Responsive recomposition
G7 Accessibility basics
G8 Correct approved assets / no unauthorized substitutes

Any major G1, G3, G4 or G5 failure blocks visual handoff.

## Quality bands

95–100
Exceptional / presentation-grade. Owner review appropriate.

90–94
Premium. Minor polish only.

85–89
Strong but not premium final. Needs one focused refinement.

75–84
Competent, visibly under-art-directed.

60–74
Basic / generic. Major visual revision.

Below 60
Reject.

## Owner calibration

Old approved Home / League / Club screens are owner-calibrated at approximately 6/10 premiumness.

They are not a 90+ target.

V5 candidates must improve materially beyond those references while preserving useful visual DNA.

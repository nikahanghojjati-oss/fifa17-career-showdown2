# QUALIFICATION UPDATE — ENVIRONMENT / BACKGROUND GATE V2

Add this gate to Luna visual qualification:

H9 ENVIRONMENT / BACKGROUND INTEGRITY

PASS requires:
- correct approved environment asset or approved V3 generated environment;
- correct screen-family lighting recipe;
- stadium/world architecture remains perceptible;
- environment supports rather than competes with live UI;
- safe zones behind title, controls, CTA and faces;
- no baked live product truth;
- desktop retains cinematic depth;
- mobile uses intentional crop/grade;
- no stretching, seams, accidental low-resolution crop or destructive over-darkening.

Distinguish:
ASSET CHECK = was the correct environment used?
ART-DIRECTION CHECK = was it used effectively?

The first can pass while the second fails.

For future 100-point scoring, Environment / Background / Lighting receives a dedicated 10 points.

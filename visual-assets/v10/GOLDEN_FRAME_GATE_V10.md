# GOLDEN FRAME GATE V10

## Purpose

No major screen is delegated to a worker until Sol has demonstrated the intended premium composition in a browser-rendered golden frame.

## Required evidence

1. current-product source anchor
2. screen truth card
3. experience thesis
4. reference decomposition
5. environment/camera plan
6. character/asset plan
7. typography plan
8. rendered desktop golden frame
9. mobile composition plan
10. visual scorecard

## Hard gates

G1 CURRENT
The visible screen reflects the current product state being designed.

G2 SCENE
The screen reads as a scene, not a themed form/dashboard.

G3 DEPTH
At least three readable depth groups exist on desktop where the screen is Level-A.

G4 DOMINANT OBJECT
One game object or experience owns the composition.

G5 ENVIRONMENT
Stadium/world remains visibly present and useful.

G6 TYPOGRAPHY
Franchise typography is unified; no page-specific random font invention.

G7 CHARACTERS
Correct screen-specific characters/poses are integrated into scene light and composition.

G8 PRODUCT SAFE
No generated art bakes volatile product state.

G9 RESPONSIVE PLAN
Mobile is explicitly recomposed.

G10 NO AI-SMELL
No generic equal-card grid, repeated rounded boxes, arbitrary glow, empty black void or pasted-on hero treatment.

## Score gate

Sol uses Premium Visual Scorecard V5 plus the V10 depth/scene checks.

Worker handoff requires:
- no failed hard gate;
- visual score >= 90/100;
- no P0/P1 art-direction defect;
- Sol judgment: genuinely premium, not merely competent.

Owner approval is not required before worker implementation unless the composition introduces a major new taste decision, but Nik remains final authority before the screen is accepted.

## Worker fidelity gate

After implementation:
- compare worker render to golden frame;
- score visual regression separately from product correctness;
- if worker degrades the golden composition, correct/demote the worker rather than weakening the golden target.

## V10 design thesis

A major Showdown screen should feel like a SCENE with interface embedded into it.

The scene has:
- camera
- world
- foreground
- midground
- background
- characters
- light
- atmosphere
- a dominant game object
- live interface
- motion
- sound hooks
- responsive variants

The UI is not placed on top of a background. The UI belongs to the scene.

## V10 depth model

Every Level-A screen uses up to seven depth planes:

P0 — distant stadium / sky / structural world
P1 — crowd / banners / architecture / large scoreboards
P2 — atmospheric light / haze / particles
P3 — characters / physical scene props
P4 — dominant object / diegetic display / tactical surface
P5 — live product controls / state UI
P6 — global chrome / focus / modal / review overlay

Not every screen needs all seven, but a cinematic screen may not collapse to one flat background plus cards.

## 3D strategy

V10 does NOT mandate expensive real-time 3D everywhere.

Use the least expensive layer that produces the required depth:

L0 — flat live DOM
L1 — cinematic transparent 3D-styled character/object renders
L2 — 2.5D scene with parallax, perspective, contact shadow and light overlays
L3 — depth-map / layered camera motion where useful
L4 — real-time WebGL / Three.js / PlayCanvas only when the interaction genuinely benefits and mobile/performance budgets pass

Default target for most major screens:
L2.

This gives a premium game feeling without turning the product into a GPU-heavy tech demo.

# AAA + FIFA 17 PRESENTATION STUDY V10

## Executive lesson

Do not copy FIFA 17 literally.

Instead combine three things:
1. FIFA 17-era navigational clarity and sports-game energy;
2. Frostbite/The Journey cinematic environmental quality;
3. Showdown's own black/gold rivalry identity.

## What FIFA 17 itself teaches

Historical FIFA 17 menu/interface material shows a presentation that prioritized readable navigation and broad background visibility rather than burying everything beneath dense dashboards.

Career Mode, Ultimate Team, The Journey and other modes used distinct presentation while remaining recognizably one product family.

That is useful for Showdown:
- shared shell;
- stable typography hierarchy;
- screen-specific imagery;
- clear active state;
- large background visual field;
- relatively direct navigation.

## What the production credits teach

FIFA 17 was not produced as one undifferentiated UI task.

Credits include distinct leadership and production roles such as:
- Presentation Director;
- UX Director;
- Lead Interface Designer;
- multiple Interface Designers;
- dedicated Companion/Web teams;
- cinematic direction/design;
- world-art and technical-art functions.

V10 cannot reproduce a AAA headcount, but it can reproduce the separation of concerns:

SOL ART DIRECTION
world, composition, franchise identity, cinematic depth, golden frame

SYSTEM / UX
current product truth, hierarchy, interaction, accessibility, responsive strategy

WORKER IMPLEMENTATION
DOM/CSS/JS, state variants, responsive production, performance

INDEPENDENT QA
visual fidelity first, product contract second

## Frostbite / The Journey lesson

FIFA 17's move to Frostbite supported a much higher cinematic/environmental quality bar for The Journey.

The relevant lesson is not engine worship.

It is that immersion comes from:
- believable environments;
- lighting;
- spatial context;
- realistic material response;
- character staging;
- cinematic camera and composition.

Showdown can approximate those benefits with pre-rendered/2.5D layers and web-native live UI.

## FUT / UI portfolio lesson

Published FIFA UI/UX portfolio work emphasizes:
- brand fit;
- dynamic menus and overlays;
- intuitive navigation;
- strong iteration;
- collaboration across UX, art direction, production and engineering;
- animated prototypes;
- accessibility.

One public FIFA UI portfolio documents dozens of iterations on a single meter component.

V10 lesson:
Premium quality requires iteration at both macro composition and micro component level.

## FIFA 17 menu-specific observations

Adopt:
- direct horizontal/section navigation;
- high contrast active state;
- strong use of background visual real estate;
- large readable type;
- mode/screen identity;
- shallow hierarchy for common actions;
- quick movement from menu to task.

Do not copy:
- proprietary FIFA/EA fonts;
- official club/league marks without rights;
- exact menu geometry;
- official sound assets;
- literal FIFA UI textures or graphic elements.

Showdown should feel like an original 2017-era premium football-game companion, not a reskin.

## Broader AAA study

AAA game UI research reinforces five rules:

### A. World + UI must cohere
UI should reflect the game's world without compromising usability.

### B. Art direction is a system
Consistent UI art requires theory, engine/implementation knowledge and quality control from concept through release.

### C. Web technology can deliver AAA UI
EA/Maxis shipped a game UI entirely in HTML/CSS/JavaScript, showing that web technology is not itself the limitation. Performance, tooling and disciplined architecture are the limitation.

### D. Game UI has a tight performance budget
Complex widgets, nested layout, rich text and heavy scene/UI composition need profiling and simplification.

### E. Menu navigation is gameplay
Focus movement, predictability, clear context and quick action matter as much as static beauty.

## Football Manager comparison

Modern Football Manager UI research is useful because it solves a different football problem: extremely information-dense management.

Important principles:
- Efficiency;
- Familiarity;
- Predictability;
- shared core system with bespoke/adapted screens;
- current information surfaced earlier;
- platform adaptation;
- fewer unnecessary clicks.

Showdown should borrow those UX principles without borrowing FM's data-heavy visual density.

## Forza comparison

Forza UI case studies show that a major hub/pause screen often establishes:
- style;
- layout;
- rules;
- guide systems;
- later screen expectations.

This supports V10's decision to revisit Home immediately after Transfer and treat it as a franchise-shell problem.

## V10 synthesis for Showdown

Premium Showdown is not:
`website + sports skin`

It is:
`sports-game presentation + web-native product truth`

The browser is an implementation platform, not the visual identity.

# SHOWDOWN VISUAL — LUNA WORKER INTERFACE V2

Luna is a production builder, not the art-direction operating system.

## Luna receives

A single compiled task packet containing:
- screen id
- exact asset IDs
- exact reference pack
- exact desktop geometry
- exact mobile geometry
- exact required states
- exact product constraints
- exact forbidden substitutions
- exact QA cases
- exact output paths

## Luna may

- implement HTML/CSS/JS for the isolated proposal
- embed approved assets
- implement responsive layouts
- implement the specified state variants
- make small code-level adjustments needed to satisfy exact geometry

## Luna may not

- select replacement character poses
- choose a new stadium/environment
- generate images
- reinterpret the visual DNA
- invent product behavior
- broaden scope
- search the full archive unless Sol explicitly asks

## Asset blocker behavior

If a named asset cannot be accessed:
return exactly which asset ID/path is unavailable.

Do not substitute a visually similar asset.

## Self-check

Luna does one lightweight visual self-check:
- correct asset IDs?
- dominant object obvious?
- no SaaS/spreadsheet impression?
- no horizontal overflow?
- mobile recomposed?

Luna's self-check is not approval.

Sol remains final reviewer.

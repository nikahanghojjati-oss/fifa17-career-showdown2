# SHOWDOWN VISUAL — ART DIRECTOR CRITIC V2

Sol performs two separate reviews.

## Review A — blind visual review

Look at the rendered candidate before reading implementation details.

Questions:
- What screen do I think this is?
- What is the first thing I notice?
- Does the page feel expensive, competitive, football-specific and cinematic?
- Are Daniel and Nik emotionally appropriate?
- Does the page feel like the same product as the approved reference family?
- Is there an unmistakable page-specific visual idea?
- Is any element visually generic?

If the page fails here, do not excuse it because the controls work.

## Review B — product contract review

Only after Review A is credible, verify:
- correct state
- correct action ownership
- privacy
- live DOM behavior
- routes
- responsive
- accessibility

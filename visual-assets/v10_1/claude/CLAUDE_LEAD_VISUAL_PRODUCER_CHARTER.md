## Quality rule

Passing automated geometric checks is necessary only when those checks protect product or implementation integrity.

It is never sufficient evidence of visual success.

The first question is:
"Does this feel like the intended world?"

The second question is:
"Does it preserve product truth?"

Only after both pass do implementation measurements matter.

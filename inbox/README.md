Nik drops ChatGPT pictures here when the Duet thread can't take an attachment:
open https://github.com/nikahanghojjati-oss/fifa17-career-showdown2/upload/claude-duet/p3-intake/inbox on the phone,
add the files, tap "Commit changes". Name each file by the asset ID from its prompt (for example
`ENV_BOARD_PLATE_RUBY_P1_2X.png`) if the phone lets you; otherwise Duet matches them by order and says which is which.

## First reproduced/evidence-backed r2 defects

1. Candidate A blocked-read ambiguity. `captureCareerModeRawBackupInputs()` uses lossy `readStorageValue()`, which converts a thrown `localStorage.getItem` into `null`. `backup.js` then treats the unread key as missing and can create an apparently valid incomplete backup. `captureCareerModeRawRestoreSnapshot()` already provides the exact fail-closed authority, so no new persistence authority is needed.

2. Offline media reconnect stale-state clobber. r2 retains `menuMediaStatusBeforeOffline` after reconnect and restores it on every later online render without proving the offline override is still active. A later legitimate live media status can therefore be overwritten by stale pre-offline text.

3. Update activation race. r2 sets `activationRequested=true` only after awaiting `CMS_ACTIVATE_UPDATE`; the waiting worker can call `skipWaiting()` and cause `controllerchange` before that continuation, so the controller-change handler can miss the requested reload intent.

4. Redundant Service Worker registration. When an existing registration is found while online, r2 verifies it but falls through to `navigator.serviceWorker.register()` again. Existing registration should be updated in place and returned; registration should occur only when no registration exists.

### 4.3 Presentation decision

Transfer Challenge should use the R8.5 black/gold final-art language primarily through DOM/CSS atmosphere, not through a new tactical expression master.

- keep the timer, phase navigator, private-entry cards and action buttons above all character art;

- use phase-derived black/gold rails, restrained glow, vignette, linework and status accents to make phase progression feel cinematic;
- do not encode state by changing manager identity, facial expression or implied opponent knowledge.

### 4.4 Shared privacy/replay guard

Therefore visual art must never:

- treat replay/witnessed historical phase rendering as a new gameplay authority;
- hide or visually downgrade the actual status/timer/action region beneath art.

## 6. Step 3 — Shared Season Commit exact-DOM decision

Shared Season Commit does not own a new screen. It reuses `#seasonReviewPanel` and injects/uses:

- `#sharedSeasonCommitStatus`
- `#sharedSeasonCommitAction`

inside the existing Season Review action hierarchy.

The exact runtime has four presentation-relevant states:

1. Results ready; coordinator can commit.
2. Results ready; non-coordinator waits for coordinator.
3. Snapshot committed; manager may acknowledge or has already acknowledged and waits for rival.
4. Both managers acknowledged.

The runtime explicitly keeps scoring locked / non-authoritative at this stage.

### 6.1 Visual hierarchy contract

The visual layer should distinguish these states using local presentation only:

- publication state: neutral information rail;
- coordinator commit opportunity: strongest gold action emphasis around the real commit action;
- waiting-for-coordinator: subdued locked rail, never a fake actionable control;
- committed-awaiting-ack: clear immutable-snapshot badge + real acknowledgement action;
- own acknowledged/waiting-rival: muted completed-side treatment;
- both acknowledged: completed rail, but no winner/loser artwork because scoring is still not authoritative here.

No second authority, no alternate commit visual control and no artwork-derived state may be introduced.

### 6.2 Asset decision

A01/A02 are sufficient as optional decorative identity anchors if space permits. No tactical or celebration master is needed for commit/acknowledgement semantics.

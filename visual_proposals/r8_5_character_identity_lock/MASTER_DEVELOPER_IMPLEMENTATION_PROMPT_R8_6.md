## DOM and final-art architecture

Treat exact current production DOM/JavaScript as behavioral authority.

Preferred implementation:

- keep real interactive DOM controls, labels and dynamic values
- use isolated generated character/background/decorative assets as presentational layers
- make decorative art non-interactive with `pointer-events:none`
- layer art behind or around live controls
- preserve keyboard/focus/ARIA behavior
- preserve mobile and Chromebook usable layouts
- use crop/fade/omit responsive rules when art competes with controls
- never bake critical dynamic text or buttons into an image

Where artwork contains decorative text that duplicates dynamic DOM content, prefer the DOM copy as authority and omit or neutralize the baked duplicate in production art.
